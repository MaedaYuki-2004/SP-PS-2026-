# 研究室MTG 個人報告スライドの書式

研究室MTG（週間報告など）の資料は、必ず `20261008_研究室MTG_テンプレート.pptx` を元にして作る。
新しく作り直さず、このファイルをコピーしてスライドを複製・書き換える（レイアウト・ロゴ・ヘッダーの帯・ページ番号はスライドマスターに入っている）。

## 全体

- サイズ：16:9（13.333 × 7.5 インチ）
- フォント：**MS PGothic**（英数字も和文も同じ）
- 発表者の表記：`SP-PS` ／ `4EP1-064  前田　侑輝`
- 各スライドに**読み上げ原稿をノートに入れる**（です・ます調、短い文）

## スライドの構成

| 枚 | レイアウト | 中身 |
|---|---|---|
| 表紙 | タイトル スライド | 「研究室 mtg」「- 個人報告 -」、プロジェクト名、学籍番号・氏名 |
| 本編 | セクションレイアウト | 今週やったこと → 説明・根拠 → 来週以降にやること |
| 補足 | セクションレイアウト | タイトルの末尾に「（補足）」。計算方法や参考文献など、聞かれたときに見せるもの |

## 本編スライドの型（セクションレイアウト）

1. **タイトル**：左上に短く（例：今週やったこと）。30〜31pt、紺 `203864`
2. **要点の帯**：タイトルの下に、薄いグレー `F3F4F6` の横長の箱。左端に紺の縦線を入れ、**そのスライドの結論を1文で**書く（28pt前後・太字・紺）
3. **本文**：次のどれかで見せる
   - 2列の比較（「これまで」グレー `6B7C96` の見出し ／ 「今週」紺 `203864` の見出し、本文は ● の箇条書き 24pt）
   - 数直線・帯グラフ（OK＝緑、NG＝赤の帯）
   - 紺の角丸ラベル＋右に説明（白文字24pt のラベル、説明は黒 `17253C` 28pt）
   - 番号つきの手順（①〜④の角丸ラベル）
4. **注記**：一番下に「＊…」で1行（紺・太字）
5. 参考文献などの細かいページは16pt、色は `5A6472`

## 色

| 用途 | 色 |
|---|---|
| メイン（紺） | `203864` |
| 本文（黒に近い紺） | `17253C` |
| サブ（灰色がかった青） | `6B7C96` |
| 小さい文字 | `5A6472` |
| 帯・箱の背景 | `F3F4F6` ／ `F4F6FA`、枠線 `D5DCE6` |

## 分量の目安

- 80秒の週間報告：本編3〜4枚（表紙を除く）＋必要なら補足。原稿は合計250〜300字程度
- 1枚に言いたいことは1つ。要点の帯の1文だけ読めば伝わるようにする
