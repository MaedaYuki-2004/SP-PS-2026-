# 研究室MTG 個人報告スライドの書式

研究室MTG（週間報告など）の資料は、このフォルダの見本を元にして作る。
新しく作り直さず、見本の .pptx をコピーしてスライドを複製・書き換える（レイアウト・ロゴ・ヘッダーの帯・ページ番号はスライドマスターに入っている）。

| 見本 | いつ使うか |
|---|---|
| `20261008_研究室MTG_テンプレート.pptx` | 基本の形。今週やったことが1つで、それを説明・根拠・来週の予定で掘り下げるとき |
| `20260917_研究室MTG_実施事項が複数の例.pptx` | 今週やったことが複数あるとき。最初に「実施内容」で 01・02… と一覧にし、相談したいこと・確認したいことを続ける |

## いちばん大事なルール

1. **1枚で伝えたいことは1つ。** 要点の帯（下記）の1文を読めば、そのスライドで何を言いたいか分かるようにする
2. **1枚あたりの文字は少なく。** 目安は**要点の帯を除いて60字前後まで**。箇条書きは**1枚3つまで、1項目15字前後**。文章で説明したいことはノート（原稿）に回す
3. 細かい数字・計算・参考文献は本編に入れず「（補足）」のスライドへ

## 全体

- サイズ：16:9（13.333 × 7.5 インチ）
- フォント：**MS PGothic**（英数字も和文も同じ）
- 発表者の表記：`SP-PS` ／ `4EP1-064  前田　侑輝`
- 各スライドの**ノートに読み上げ原稿**を入れる。先頭に `【N枚目／○秒】タイトル` と書き、です・ます調の短い文で
- 文字の大きさ：タイトル30〜31pt、要点の帯28〜31pt、本文24〜30pt。小さくても補足の16pt まで

## スライドの構成

| 枚 | レイアウト | 中身 |
|---|---|---|
| 表紙 | タイトル スライド | 「研究室 mtg」「- 個人報告 -」、プロジェクト名、学籍番号・氏名 |
| 実施内容（複数のとき） | セクションレイアウト_引用有 | 01・02…の大きな番号＋グレーの箱。箱の中は**太字の見出し1行＋補足1行だけ** |
| 本編 | セクションレイアウト | 今週やったこと → 説明・根拠 → 相談したいこと・確認したいこと → 来週以降にやること |
| 補足 | セクションレイアウト | タイトルの末尾に「（補足）」。計算方法や参考文献など、聞かれたときに見せるもの |

## 本編スライドの型（セクションレイアウト）

1. **タイトル**：左上に短く（例：今週やったこと、相談したいこと）。紺 `203864`
2. **要点の帯**：タイトルの下に、薄いグレー `F3F4F6` の横長の箱。左端に紺の縦線を入れ、**そのスライドの結論を1文で**書く（太字・紺）
3. **本文**：次のどれかで見せる（同じ型が続かないように変える）
   - 2列の比較（「これまで」グレー `6B7C96` の見出し ／ 「今週」紺 `203864` の見出し、本文は ● の箇条書き）
   - 横に3つ並べたカード（白地・角丸・薄い影。太字の見出し＋2行以内の説明）
   - 縦に積んだカード（太字の見出し＋1行の説明）
   - 数直線・帯グラフ（OK＝緑、NG＝赤の帯）
   - 紺の角丸ラベル＋右に説明
   - 番号つきの手順（①〜④の角丸ラベル）
   - 文字を1つずつ箱に入れた図（例：「が／っ／こ／う」）
4. **締めの1文**：一番下に、紺のグラデーション（`16294A`〜`27467A`）の角丸の帯に白文字で、言いたいことや聞きたいことを1文。または「＊…」の注記を紺・太字で1行

## 色

| 用途 | 色 |
|---|---|
| メイン（紺） | `203864` |
| 締めの帯（濃い紺のグラデーション） | `16294A` 〜 `27467A` |
| 本文（黒に近い紺） | `17253C` |
| サブ（灰色がかった青） | `6B7C96` |
| 小さい文字 | `5A6472` |
| 帯・箱の背景 | `F3F4F6` ／ `F4F6FA` ／ `F5F8FD`、枠線 `D5DCE6` |

## 分量の目安

- 80秒の週間報告：本編3〜4枚（表紙を除く）＋必要なら補足。原稿は合計250〜300字程度（1枚20秒前後）
