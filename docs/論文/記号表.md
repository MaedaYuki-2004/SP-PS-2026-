## 0. 確定する前に指導教員と確認したい点

| # | 確認したいこと | この案での扱い |
|---|---------------|--------------|
| 1 | お手本・学習者を区別する上付き添字 | 立体の $\mathrm{ref}$（お手本）・$\mathrm{lrn}$（学習者）。H/L の L と紛れないよう 1 文字にしない |
| 2 | 研究室・投稿先に決まった記法（テンプレート）があるか | 無い前提で、ISO 80000-2（変数は斜体、説明の添字・関数名・単位は立体）に合わせた。ただしベクトルは、信号処理の論文でよく使う立体の太字（`\mathbf`）にした（ISO では太字の斜体） |

| 5 | 「モーラ」と「Julius の単位」の区別をどこまで書くか | 記号は Julius の単位で数え（$k$, $K$）、長音のまとまりは別の添字 $g$, $G$ にした |

## 1. 表記の基本ルール

| 種類 | 書体 | 例 |
|------|------|----|
| スカラーの変数 | 斜体（イタリック） | $p_t$, $\kappa$, $S_{\mathrm{A}}$ |
| ベクトル | 太字の小文字（立体。`\mathbf`） | $\mathbf{x}_n$, $\mathbf{c}_t$ |
| 系列（ベクトルの並び）・行列 | 太字の大文字（立体。`\mathbf`） | $\mathbf{X}$, $\mathbf{C}$ |
| 集合 | 筆記体（`\mathcal`） | $\mathcal{V}$, $\mathcal{T}_k$, $\mathcal{W}$ |
| 説明のための添字（変数でないもの） | **立体**（ローマン） | $S_{\mathrm{nuc}}$, $F^{\mathrm{ref}}$, $\theta_{\mathrm{flat}}$ |
| 番号の添字（変数） | 斜体 | $p_t$, $\bar{p}_k$, $e_g$ |
| 関数名・演算子 | 立体 | $\mathrm{med}$, $\exp$, $\log_2$, $\mathrm{DTW}$ |
| 単位 | 立体、数値との間に半角スペース | 10 ms, 1.0 st, 5500 Hz |
| 定数（設計値） | 記号を付け、値は記号表と本文の表で示す | $\theta_{\mathrm{nuc}} = 1.0$ st |

その他の決まり：

- **お手本と学習者**は上付きの $\mathrm{ref}$ / $\mathrm{lrn}$ で区別する（例：$\bar{p}^{\mathrm{ref}}_k$）。どちらにも当てはまる説明では添字を省く。
- **下付きは「何の量か・何番目か」、上付きは「誰の量か」** に使う。べき乗と紛れるときは括弧を付ける：$(\sigma^{\mathrm{lrn}}_k)^2$。
- **単語全体の点数は大文字 $S$、モーラ（音）ごとの点数は小文字 $s$**。
- **3軸は添字 A・D・V** で表す：A = アクセント（Accent）、D = モーラ長（Duration）、V = 母音品質（Vowel）。「長さ」を L にしないのは H/L の L と紛れるため。
- 半音の単位は **st**（semitone）、Bark の単位は **Bark** と書く。
- しきい値は $\theta$、重みは用途ごとに $\alpha$（アクセント）・$w$（長さ）・$\omega$（母音）に分ける。
- 指数関数は $\exp(\cdot)$ と書き、$e^{x}$ の形は使わない（$e$ は長さの割合の差 $e_g$ に使っているため）。

## 2. 添字・集合・演算子

### 2.1 番号（インデックス）

| 記号 | 意味 | 範囲 |
|------|------|------|
| $t$ | 音声のフレーム番号（10 ms ごと） | $t = 1, \dots, N_{\mathrm{a}}$ |
| $k$ | モーラ（Julius の単位）の番号 | $k = 1, \dots, K$ |
| $g$ | 長音のまとまりの番号（長音でないモーラは 1 つで 1 まとまり） | $g = 1, \dots, G$ |
| $n$ | 映像のフレーム番号 | $n = 1, \dots, N_{\mathrm{v}}$ |
| $j$ | 顔のランドマーク番号（MediaPipe Face Mesh の番号のまま。`refine_landmarks=True` なので虹彩の 10 点を含む） | $j \in \{0, \dots, 477\}$ |
| $i$ | 練習記録の番号（新しい順・古い順は文中で明記） | $i = 1, \dots, N_{\mathrm{rec}}$ |

### 2.2 集合

| 記号 | 意味 |
|------|------|
| $\mathcal{T}_k$ | モーラ $k$ に属する音声フレームの集合 |
| $\mathcal{G}_g$ | まとまり $g$ に属するモーラの集合 |
| $\mathcal{V}$ | 有声フレームの集合（F0 が測れたフレーム） |
| $\mathcal{V}_k = \mathcal{V} \cap \mathcal{T}_k$ | モーラ $k$ の有声フレーム |
| $\mathcal{V}^{\mathrm{both}}_k = \mathcal{V}^{\mathrm{ref}}_k \cap \mathcal{V}^{\mathrm{lrn}}_k$ | モーラ $k$ で、お手本と学習者の両方が有声のフレーム |
| $\mathcal{K}$ | 高さを測れたモーラ（有声 3 フレーム以上かつ 30% 以上）の集合 |
| $\mathcal{K}_{\mathrm{stb}}$ | 学習者の有声フレームが 3 以上のモーラの集合（安定度の平均に使う。30% の条件は無い） |
| $\mathcal{K}_{\mathrm{AV}}$ | 口と声のずれを比べたモーラの集合 |
| $\mathcal{W}$ | DTW の整合経路（対応付けたフレーム番号の組の列） |
| $\lvert \cdot \rvert$ | 集合の要素数・系列の長さ（例：$\lvert \mathcal{W} \rvert$ は経路の長さ、$\lvert \mathbf{C} \rvert$ は MFCC のフレーム数） |

### 2.3 演算子・関数

| 記号 | 意味 |
|------|------|
| $\mathrm{med}_{x \in \mathcal{X}} x$ | 中央値 |
| $Q_{90}(\cdot)$ など | パーセンタイル。添字は百分率の値で書く（$Q_{90}$ は第 90 パーセンタイル、$Q_{100\pi_{\mathrm{L}}}$ も使う）。$q$ は長音・促音の比に使っているので、添字に $q$ は使わない |
| $\mathrm{clip}(x, x_{\min}, x_{\max})$ | $\min(x_{\max}, \max(x_{\min}, x))$ |
| $\lvert x \rvert$ | 絶対値 |
| $\lVert \mathbf{x} \rVert$ | ユークリッドノルム |
| $d(\mathbf{x}, \mathbf{y})$ | ユークリッド距離 $\lVert \mathbf{x} - \mathbf{y} \rVert$ |
| $\mathrm{DTW}(\mathbf{X}, \mathbf{Y})$ | 系列 $\mathbf{X}, \mathbf{Y}$ の DTW 累積距離（FastDTW、radius 1、距離は $d$） |
| $z(F)$ | Hz から Bark への変換（Traunmüller, 1990） |
| $\mathrm{round}(\cdot)$ | 四捨五入（桁は本文で示す） |

## 4. 統一した記号で書いた主な式

点数（$S$・$S_{\mathrm{A}}$・$S_{\mathrm{D}}$・$S_{\mathrm{V}}$・$P_{\mathrm{AV}}$・モーラ別スコアなど）は、コードでは小数第 1 位で丸めている。式では丸めを省いた。

### 4.1 合計点

$$
S = \mathrm{clip}\bigl(S_{\mathrm{A}} + S_{\mathrm{D}} + S_{\mathrm{V}} - P_{\mathrm{AV}},\ 0,\ 100\bigr)
$$

### 4.2 ピッチ

$$
p_t = 12 \log_2 \frac{f_{0,t}}{\tilde{f}_0}, \qquad
\tilde{f}_0 = \underset{t \in \mathcal{V}}{\mathrm{med}} f_{0,t}, \qquad
\bar{p}_k = \underset{t \in \mathcal{V}_k}{\mathrm{med}} p_t
$$

### 4.3 アクセント

$$
\tilde{S}_{\mathrm{A}} = \alpha_{\mathrm{nuc}} S_{\mathrm{nuc}} + \alpha_{\mathrm{cor}} S_{\mathrm{cor}} + \alpha_{\mathrm{HL}} S_{\mathrm{HL}} + \alpha_{\mathrm{stb}} S_{\mathrm{stb}},
\qquad
S_{\mathrm{A}} = \min\Bigl(50,\ \tfrac{50}{60}\tilde{S}_{\mathrm{A}} + 3.0\Bigr)
$$

$$
S_{\mathrm{nuc}} = \max\Bigl(0,\ 60 - \frac{60\,\lvert \kappa^{\mathrm{lrn}} - \kappa^{\mathrm{ref}} \rvert}{\max(K+1,\,3)}\Bigr),
\qquad
S_{\mathrm{cor}} = 60 \cdot \frac{\rho + 1}{2}
$$

$$
h_k =
\begin{cases}
\mathrm{H} & (\bar{p}_k > \theta_{\mathrm{HL}}) \\
\mathrm{L} & (\text{otherwise})
\end{cases},
\qquad
S_{\mathrm{HL}} = 60\, a_{\mathrm{HL}},
\qquad
S_{\mathrm{stb}} = \max\Bigl(0,\ 60\Bigl(1 - \frac{1}{\lvert \mathcal{K}_{\mathrm{stb}} \rvert} \sum_{k \in \mathcal{K}_{\mathrm{stb}}} \frac{\sigma^2_{+,k}}{\sigma^2_{\max}}\Bigr)\Bigr)
$$

平坦ゲート：$W^{\mathrm{lrn}} < \min\bigl(\theta_{\mathrm{flat}},\ 0.5\,W^{\mathrm{ref}}\bigr)$ のとき $\tilde{S}_{\mathrm{A}} \leftarrow \min(\tilde{S}_{\mathrm{A}}, 25)$。

$\mathcal{K}_{\mathrm{stb}}$ が空なら $S_{\mathrm{stb}} = 30$。相関か安定度を計算できないときは、残りの指標で重みを変える（README §6.3）。

### 4.4 モーラ長

$$
\bar{e} = \frac{\sum_{g} w_g\, e_g}{\sum_{g} w_g},
\qquad
\tilde{S}_{\mathrm{D}} = \max\Bigl(0,\ 40\Bigl(1 - \frac{\bar{e}}{\bar{\eta}}\Bigr)\Bigr),
\qquad
S_{\mathrm{D}} = \frac{30}{40}\tilde{S}_{\mathrm{D}}
$$

### 4.5 母音品質

$$
\delta^{\mathrm{V}}_g = \sqrt{
\Bigl(\frac{z(\gamma F^{\mathrm{ref}}_{1,g}) - z(F^{\mathrm{lrn}}_{1,g})}{b_1}\Bigr)^2 +
\Bigl(\frac{z(\gamma F^{\mathrm{ref}}_{2,g}) - z(F^{\mathrm{lrn}}_{2,g})}{b_2}\Bigr)^2 }
$$

$$
\bar{\delta}^{\mathrm{V}} = \frac{\sum_g \omega_g \delta^{\mathrm{V}}_g}{\sum_g \omega_g},
\qquad
S_{\mathrm{V}} = \mathrm{clip}\bigl(20 \exp(-\bar{\delta}^{\mathrm{V}}),\ 0.5,\ 20\bigr)
$$

### 4.6 モーラ別スコア

3 軸とも「ずれ $\delta$ を指数関数で 0〜100 にする」同じ形になるように記号をそろえた。

$$
s^{\mathrm{A}}_k = 100 \exp(-4\,\delta^{\mathrm{A}}_k), \qquad
s^{\mathrm{D}}_k = 100 \exp(-3\,\delta^{\mathrm{D}}_{g(k)}), \qquad
s^{\mathrm{V}}_k = 100 \exp(-\delta^{\mathrm{V}}_{g(k)})
$$

$$
\delta^{\mathrm{A}}_k = \mathrm{med}_{t \in \mathcal{V}^{\mathrm{both}}_k} \bigl\lvert \check{p}^{\mathrm{ref}}_t - \check{p}^{\mathrm{lrn}}_t \bigr\rvert,
\qquad
\delta^{\mathrm{D}}_g = w_g \lvert 1 - r_g \rvert
$$

$g(k)$ はモーラ $k$ が属するまとまりの番号。

### 4.7 口形分析

$$
x_{n,j} = \frac{\lVert \mathbf{u}_j - \mathbf{u}_{\mathrm{c}} \rVert}{\lVert \mathbf{u}_{33} - \mathbf{u}_{263} \rVert},
\qquad
\mathbf{u}_{\mathrm{c}} = \tfrac{1}{2}(\mathbf{u}_{13} + \mathbf{u}_{14}),
\qquad
o_n = \frac{\lVert \mathbf{u}_{13} - \mathbf{u}_{14} \rVert}{\lVert \mathbf{u}_{61} - \mathbf{u}_{291} \rVert}
$$

ここで $j$ は唇の輪郭の 20 点（`LIP_POINTS`）のランドマーク番号で、$\mathbf{x}_n$ はこの 20 個を並べたもの。

$$
\bar{d}_{\mathrm{lip}} = \frac{\mathrm{DTW}(\mathbf{X}^{\mathrm{ref}}, \mathbf{X}^{\mathrm{lrn}})}{\lvert \mathcal{W} \rvert},
\qquad
S_{\mathrm{lip}} = \mathrm{clip}\bigl(\mathrm{round}(100 - 200\,\bar{d}_{\mathrm{lip}}),\ 0,\ 100\bigr)
$$

### 4.8 口と声のタイミング

$$
\tilde{\Delta}_k = \Delta_k - \mathrm{med}_{k' \in \mathcal{K}_{\mathrm{AV}}} \Delta_{k'},
\qquad
\theta_k =
\begin{cases}
\theta_{\mathrm{vf}} & (\tilde{\Delta}_k > 0) \\
\theta_{\mathrm{mf}} & (\text{otherwise})
\end{cases}
$$

$$
\lambda_k = \mathrm{clip}\Bigl(\frac{\lvert \tilde{\Delta}_k \rvert - \theta_k - \varepsilon}{\theta_{\mathrm{full}} - \theta_k},\ 0,\ 1\Bigr),
\qquad
P_{\mathrm{AV}} = \frac{P_{\max}}{\lvert \mathcal{K}_{\mathrm{AV}} \rvert} \sum_{k \in \mathcal{K}_{\mathrm{AV}}} \lambda_k
$$

$\lvert \mathcal{K}_{\mathrm{AV}} \rvert < 3$ などのときは $P_{\mathrm{AV}}$ を「定義しない」（0 ではない）。

## 8. LaTeX マクロの使い方

[`spps-notation.sty`](spps-notation.sty) を論文の `.tex` と同じフォルダに置き、プリアンブルで読み込みます。

```latex
\usepackage{spps-notation}
```

記号をマクロで書いておくと、あとで記号を変えることになっても `.sty` を 1 か所直すだけで論文全体が変わります。

```latex
合計点は $\Stot = \clip(\SA + \SD + \SV - \Pav, 0, 100)$ とする。
モーラ $k$ の高さ $\mpitch{k}$ はお手本 $\mpitch[\sref]{k}$ と学習者 $\mpitch[\slrn]{k}$ で別々に求める。
```

主なマクロ：

| マクロ | 出力 | マクロ | 出力 |
|-------|------|-------|------|
| `\sref`, `\slrn` | $\mathrm{ref}$, $\mathrm{lrn}$ | `\med`, `\clip`, `\DTW`, `\pct{90}` | $\mathrm{med}$, $\mathrm{clip}$, $\mathrm{DTW}$, $Q_{90}$ |
| `\Stot`, `\SA`, `\SD`, `\SV`, `\Pav` | $S$, $S_{\mathrm{A}}$, $S_{\mathrm{D}}$, $S_{\mathrm{V}}$, $P_{\mathrm{AV}}$ | `\SAraw`, `\SDraw` | $\tilde{S}_{\mathrm{A}}$, $\tilde{S}_{\mathrm{D}}$ |
| `\Snuc`, `\Scor`, `\SHL`, `\Sstb` | $S_{\mathrm{nuc}}$ ほか | `\anuc`, `\acor`, `\aHL`, `\astb` | $\alpha_{\mathrm{nuc}}$ ほか |
| `\fz{t}`, `\pitch{t}`, `\mpitch{k}` | $f_{0,t}$, $p_t$, $\bar{p}_k$ | `\nuc`, `\corr` | $\kappa$, $\rho$ |
| `\share{g}`, `\lendiff{g}`, `\lenw{g}` | $\eta_g$, $e_g$, $w_g$ | `\bark{F}`, `\spk` | $z(F)$, $\gamma$ |
| `\vdist{g}`, `\adist{k}`, `\ddist{g}` | $\delta^{\mathrm{V}}_g$, $\delta^{\mathrm{A}}_k$, $\delta^{\mathrm{D}}_g$ | `\ms[A]{k}` | $s^{\mathrm{A}}_k$ |
| `\lipvec{n}`, `\LipSeq`, `\open{n}` | $\mathbf{x}_n$, $\mathbf{X}$, $o_n$ | `\avoff{k}`, `\avrel{k}`, `\avloss{k}` | $\Delta_k$, $\tilde{\Delta}_k$, $\lambda_k$ |

上付きを付けるマクロは省略可能な引数 `[...]` で誰の量かを指定します（例：`\mpitch[\sref]{k}` → $\bar{p}^{\mathrm{ref}}_k$）。

> **Word で書く場合：** Word の数式エディタは LaTeX 形式の入力を受け付けます（数式ツール →「LaTeX」）。§4 の式をそのまま貼れます。その場合も記号はこの表のとおりにしてください。
